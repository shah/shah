## Principles Check

<!-- Work through every line before Phase 0. Check a box only when you can
name the specific answer, not when it feels generally true. -->

- [ ] **Claims standard respected.** Does every claim this plan will
      publish trace to something verifiable, or is it clearly labeled as
      opinion? See spec 0001's claims standard.
- [ ] **Property boundary respected.** Does this plan cite another
      property's activity as proof of a claim about a different property,
      or blur which entity actually holds a role, right, or fact? If yes,
      stop — name the correct entity instead.
- [ ] **Status honesty.** If this plan touches a role, venture, or
      relationship whose current status can't be confirmed from a recent
      first-party source, is it labeled "Former" or "Previously served
      as" rather than stated as current?
- [ ] **Non-disclosure respected.** Does this plan avoid publishing
      anything spec 0001 says this repository doesn't publish (private
      contact details beyond what's already public, financial specifics,
      unverified personal facts)?
- [ ] **Consistent with the personal principles.** Does this plan's
      substance sit comfortably with the sentence spec 0001 quotes — kind,
      generous, empathetic, intellectually honest and consistent, useful
      to others — or does it need a second look?

If a box can't be checked, this plan is not ready. Either resolve it, or
record the specific exception and who approved it under Complexity below
— never leave a box silently unchecked.
